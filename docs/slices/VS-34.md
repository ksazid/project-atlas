## Delivered runtime scope

- Today ready state now says `1 thing worth doing today` and exposes semantic label `BEST MOVE`;
- recommendation/task title uses strong sans-serif action typography while the `Today` page title retains the established serif editorial treatment;
- Impact / Effort / Confidence are collapsed into one compact evidence row using only existing server-provided values;
- primary action is `I’ll do this` with existing Apply semantics;
- secondary action is `Why this?`, opening Opportunity Detail;
- one-tap overflow exposes `Later` and `Not relevant`, keeping both within two taps while preserving existing skip/not-relevant semantics;
- the duplicate `Want the reasoning?` supporting card is removed;
- native pull-to-refresh, truthful freshness state, stale-refresh preservation, safe degraded states and no-filler policy remain intact;
- Settings, Context and Feedback replace the custom Profile text `headerLeft` with native/light Atlas Profile back treatment and retain a minimal green deep-link fallback when no native back stack exists;
- Today / History / Goals / Profile topology remains unchanged;
- Today remains cross-industry and provider-neutral.

## Cross-industry and product rules

- Recommendation text continues to come from the evidence-qualified Opportunity for the active business.
- No restaurant-specific logic is introduced into Atlas Core.
- No Business Pulse, What Changed, Ask Atlas or new Opportunity queue is introduced.
- No fabricated metrics, percentages or business facts are permitted.
- Opportunity Detail remains the source for Why Now, evidence, assumptions, limitations, expiry and Knowledge Pack metadata.
- `Later` remains existing Skip semantics and `Not relevant` remains existing not-relevant semantics.

## Accessibility

- Dynamic Type behavior and current Reduce Motion/press behavior are preserved.
- Action controls retain accessible roles/labels and minimum touch targets.
- Meaning is not encoded by color alone.
- Overflow actions remain reachable within two taps.
- pushed-screen fallback navigation retains an accessible `Back to Profile` label.
