# VS-23 — Evidence-Aware Restaurant/Café Opportunity Generation

## Status

Active — implementation approved.

## Requirements

- FR-05 Business Context
- FR-06 Knowledge Pack support
- FR-07 Today’s Focus
- FR-08 Opportunity Detail
- FR-16 Empty and degraded states

## Goal

Consume the exact VS-20 `ResolvedKnowledgeBundle` and generate one deterministic, evidence-qualified Today’s Focus for a current Business Goal. Restaurant/Café patterns are used only when the Restaurant/Café category manifest is present and required evidence exists. Otherwise Atlas uses only eligible Core patterns or returns an honest no-focus state.

## In scope

- deterministic candidate generation from packaged Manifest v2 patterns;
- explicit evidence-rule evaluation;
- goal matching and prioritisation;
- application-controlled confidence;
- cooldown duplicate suppression;
- deterministic ranking and one selected Today’s Focus;
- structured evidence snapshot with exact pack versions + bundle fingerprint;
- Today’s Focus API integration;
- Opportunity Detail parsing for the new evidence snapshot;
- safe no-focus/degraded states;
- tenant isolation and regression coverage.

## Out of scope

- external AI inference;
- public discovery/location changes;
- VS-22 multi-source discovery;
- new providers/connectors;
- dynamic Knowledge Pack installation;
- production deployment.

## Parallel delivery rule

This branch is intentionally isolated from the parallel `atlas/vs22-multi-source-discovery` work. Before VS-23 merges, it must be updated to the then-current `main` and recertified at the new exact SHA.
