# VS-45 — Profile Live Data Summary

## Outcome
Profile reflects business-data freshness using the existing connector status.

## Rules
- Reuse the existing connector contract; no new API surface.
- A saved connector alone is not Live.
- Live requires a successful sync timestamp.
- Connector lookup failure must not make Profile unavailable.
- Business Context and Business Data remain visually matched.

## Acceptance
1. Profile loads business hub and connector state together.
2. Successful sync shows relative freshness on the Business Data card.
3. Connected-without-success shows a waiting state.
4. Attention state remains distinct.
5. Connector lookup failure falls back to generic Business Data copy.
6. Manage connectors still routes to `/connectors`.
