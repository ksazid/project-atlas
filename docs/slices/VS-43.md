# VS-43 — Connector Error & Settings Alignment

## Outcome
Repair the Expo pilot experience shown in owner screenshots without changing connector contracts or production behavior.

## Scope
- keep schedule-update failures visually distinct from sync failures;
- keep the connector's saved state truthful while recovery copy remains actionable;
- align Settings with the approved Profile/Business Data hierarchy and remove the duplicate native Settings title;
- refresh the isolated Expo Go harness and Atlas test API after certification.

## Protected boundaries
No API contract, database, migration, Drive permission, ingestion policy, recommendation logic, release workflow or production configuration changes.

## Acceptance
1. A schedule failure no longer presents as a failed sync.
2. Sync failure still offers a truthful retry.
3. Settings uses one branded Atlas hierarchy with Profile-consistent typography, spacing and cards.
4. CI, Security baseline and Product Intake pass on the exact implementation head before the test harness is refreshed.
5. Production remains untouched.
