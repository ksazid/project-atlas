# VS-19 — Restaurant/Café Reference Intelligence

## Requirement traceability
- FR-06 — Knowledge Pack support
- Depends on VS-18 Manifest Schema v2

## Acceptance criteria
1. A packaged Manifest v2 exists for canonical category `restaurant-cafe`.
2. Exact version is `1.0` and layer is `category`.
3. Supported subcategories are `restaurant`, `cafe`, `bakery`, `takeaway`.
4. Manifest validates under the server-owned VS-18 policy.
5. It includes category-relevant KPIs, evidence rules, Opportunity patterns, execution templates, measurement suggestions, seasonality and guardrails.
6. Opportunity patterns are evidence-gated and make no guaranteed business-result claim.
7. The pack is provider-neutral and requires no Wolt/Bolt/private API/paid provider.
8. No other category pack is introduced in this slice.
9. No database migration, public endpoint, remote pack installation, release or production enablement is introduced.

## Risk
Medium. This is packaged domain intelligence consumed by later runtime resolution/generation slices.
