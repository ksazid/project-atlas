# VS-20 — Automatic Knowledge Bundle Resolution

## Requirement traceability
- FR-06 — Knowledge Pack support
- Depends on VS-18 Manifest Schema v2 and VS-19 Restaurant/Café Reference Intelligence

## Acceptance criteria
1. Atlas resolves an effective bundle without owner selection of technical packs.
2. The exact current Generic Business Core assignment is required and must match an available packaged Core Manifest v2.
3. Restaurant/Café automatically receives the packaged Restaurant/Café Category manifest.
4. Categories without a packaged Category manifest receive Core only, not fabricated category intelligence.
5. Subcategory is accepted only from owner-confirmed canonical Business Profile evidence and is never re-inferred during resolution.
6. Only owner-confirmed, non-empty Business Context entries are included.
7. Country, timezone, currency and primary location are included as Local/Market facts.
8. Persisted Business Memory items are included as a distinct Memory layer.
9. Every packaged manifest records exact key/version/fingerprint and the complete bundle has a stable semantic fingerprint.
10. Equivalent reordered inputs produce the same bundle fingerprint.
11. No database migration, pack-picker UI, public technical pack endpoint, remote installation, provider dependency, release or production enablement is introduced.

## Risk
Medium. The resolver becomes the deterministic intelligence input for subsequent Opportunity generation.

The Product Owner approved the next five Atlas slices on 2026-08-10 and instructed implementation, fixes, certification and merge after required gates pass. VS-20 is the third slice in that approved sequence.
