# VS-31 — Native Navigation Alignment

## Status

Active runtime slice. Scope, design and implementation are approved under the Product Owner's standing authorization on 2026-08-12. Certification is pending exact-head verification.

## Requirements

- FR-03 — Business Profile
- FR-12 — History
- FR-16 — Empty and degraded states

## Goal

Resolve the long-standing mismatch between Atlas's approved four-destination navigation and the inherited five-tab runtime without removing Business, Context or Settings capabilities.

## Approved persistent navigation

1. Today
2. History
3. Goals
4. Profile

Business Hub remains the Profile root. Context and Settings become pushed Profile-detail routes. History becomes a true tab root while retaining the `/history` path.

## Scope

- keep Expo Router NativeTabs from VS-28;
- align tab labels/routes to Today / History / Goals / Profile;
- move History into the tab route group;
- move Context and Settings out of the tab group into root Stack detail routes;
- add Profile links to Context and Settings;
- add visible accessible Back-to-Profile affordances on Context/Settings;
- remove the obsolete Back action from History;
- add Android History fallback icon;
- preserve all existing screen/domain behavior;
- deterministic mobile regressions for tab count, labels, route placement and reachability.

## Out of scope

- API/backend/database changes;
- migrations;
- Business Hub redesign;
- Context workflow redesign;
- Settings/reset redesign;
- auth changes;
- Today’s Focus/recommendation changes;
- deployment/release/EAS/OTA/production enablement.

## Decision

DEC-10 resolves the temporary navigation deferrals in DEC-02, DEC-03 and DEC-09 for future runtime work. Historical decisions remain preserved.

## Acceptance

- exactly four native tab triggers exist: `index`, `history`, `goals`, `profile`;
- labels are Today, History, Goals, Profile;
- Context and Settings remain reachable from Profile but are no longer persistent tabs;
- `/history`, `/context`, `/settings` remain stable paths;
- History is tab-bar-aware and has no misleading Back button;
- Context and Settings have accessible Back-to-Profile behavior and no tab-bar spacing;
- Business Hub, Context, Settings and History feature behavior remains intact;
- full mobile/preflight/CI/security/product gates pass at the exact implementation SHA;
- no production deployment or release occurs.

## Evidence

Pending implementation and exact-head certification.
