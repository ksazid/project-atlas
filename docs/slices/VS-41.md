# VS-41 — Device CSV Fallback

Activate the secondary device CSV fallback on Business Data while Google Drive remains the primary persistent pilot connector.

The mobile flow selects one CSV, previews it through the existing owner-only operational-upload preview endpoint, shows the returned privacy-safe summary, and requires explicit confirmation. Confirmation resends the same selected CSV with PreviewFingerprint to the existing operational-upload confirm endpoint. The app does not convert the CSV to base64 or persist raw bytes; it keeps only the transient selected-file reference required to complete the flow.

API, database, normalization, ingestion policy, Google Drive permissions, release and production paths remain unchanged.

Regression evidence: tests/mobile/vs41-device-csv-fallback.test.mjs.
