# VS-05 — Opportunity Detail

## Status

Implementation is complete in draft PR #9 and has entered repository testing.

## Outcome

Allow a Business owner to inspect the full evidence-backed reasoning behind the current Opportunity without changing the PES Mobile framework or duplicating Today’s Focus logic.

## Requirement

- FR-08 — Opportunity Detail

## Implemented

- business-isolated `GET /api/v1/businesses/{businessId}/opportunities/{opportunityId}`;
- exact goal resolution and safe missing-goal handling;
- Evidence items with category, label, value and provenance source;
- Atlas interpretation separated from Evidence;
- reason, why-now, confidence, Expected Impact and effort;
- assumptions, limitations and source categories;
- expiry and current status calculation;
- exact Knowledge Pack key/version retention;
- mobile `/opportunities/[opportunityId]` route from Today’s Focus;
- loading, missing, unavailable and expired states;
- explicit non-executing VS-06 Execution Kit boundary;
- deterministic policy tests including malformed historical evidence fallback.

## Dependencies

- Certified VS-03 Knowledge Pack Foundation
- Certified VS-04 Today’s Focus

## Out of scope

- Execution Kit creation or editing;
- autonomous publishing or external action;
- production AI provider execution;
- embeddings, vector storage or semantic retrieval;
- PES navigation, authentication, state-management or design-system restructuring;
- deployment, release or production enablement.
