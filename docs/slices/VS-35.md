# VS-35 — Pilot Operations

## Purpose
Complete PRD FR-18 with a minimal internal Pilot Operations capability for authorised `PilotOperator` and `PlatformAdministrator` users.

## Base
Fresh post-VS-34 main: `345045cd40a97daac547aa2b847e793a20bb5fb5`.

## Authority
- PRD FR-18
- TRD Pilot Operations, Opportunity lifecycle, audit and authorization requirements
- DESIGN v1.2
- PES/Loop governance
- DEC-11

## Scope
- inspect pilot Businesses and readiness/quality/safety signals;
- persist compact Opportunity-generation diagnostics without raw provider/model payloads;
- append internal support/intervention provenance;
- assist Business Profile correction using `operator-assisted` provenance and `OwnerConfirmed=false`;
- collaboratively prepare currently eligible evidence-backed Opportunities using the existing generator;
- explicitly withdraw unsafe/unsuitable Opportunities with required reason, optimistic concurrency and audit;
- add a bounded `/operator` review surface outside the owner tab shell.

## DEC-11 boundary
Internal operators never impersonate Business owners. Operator mutations use dedicated `InternalOperator` commands and preserve actor, target, reason/provenance and audit.

## Owner boundary
Owner navigation remains exactly Today / History / Goals / Profile. No operator tab. Owner Apply/Skip/Not Relevant semantics remain owner-controlled.

## Out of scope
- full admin platform;
- owner impersonation;
- free-form recommendation authoring;
- automatic withdrawal from feedback alone;
- external helpdesk/CRM;
- Redis/queue/warehouse/new microservice;
- attachments;
- production deployment/release/EAS/OTA/production DB mutation.

## Compatibility note
The earlier paused Pilot Operations work on PR #57 is preserved only as TDD/evidence history. Runtime overlap scan against VS-33/VS-34 found no API/domain/migration file collision. VS-35 must be implemented and certified from fresh main; the old branch is never a merge candidate.

## Success
An authorised internal operator can review pilot health, record support work, assist profile correction truthfully, prepare evidence-backed Opportunities, and explicitly withdraw unsafe content with audit, while owner authority and navigation remain unchanged.
