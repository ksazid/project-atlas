# VS-37 — Evidence-Aware Today Cooldown Repair

## Status
Certified. Runtime frozen at `c7e683dda86482cff4d659a4d88d9f9fdd087aef`.

## Purpose
Repair Today duplicate suppression so a Knowledge Pack Opportunity pattern can be reconsidered inside its normal cooldown when the owner materially changes the goal/evidence that pattern actually uses, without allowing unrelated Context edits to create repetitive recommendations.

## Base
Merged VS-36 main: `48f1ecd6359ff9beb74687fe2aeead1d2afb3802`.

## Authority
- PRD Opportunity eligibility, FR-05 and FR-07
- TRD evidence/provenance and deterministic application-policy boundaries
- DESIGN v1.2 truthful Today/no-focus behavior
- PES/Loop governance
- Existing Knowledge Pack `CooldownDays` policy

## Implemented scope
- pattern evidence is resolved before cooldown evaluation;
- deterministic cooldown identity uses pattern + selected goal context + pattern-resolved EvidenceIds;
- future Opportunity EvidenceJson is schema v2 and stores `cooldownFingerprint`;
- complete schema-v1 historical snapshots derive the equivalent identity without database backfill;
- incomplete same-pattern legacy snapshots fail closed to conservative suppression;
- Opportunity evidence parsing accepts both supported schema-v1 and schema-v2 snapshots;
- existing ranking, cooldown durations, policy-only eligibility, owner decisions and no-focus behavior are preserved.

## Explicit non-goals preserved
- no Knowledge Pack cooldown-duration change;
- no whole Business/Knowledge bundle fingerprint as duplicate identity;
- no new Opportunity patterns or generic fallback recommendations;
- no Today UI/navigation/copy change;
- no action-decision status-semantic change;
- no database migration/backfill;
- no connectors, model prompts/providers or external action;
- no production release, EAS/OTA or production database mutation.
