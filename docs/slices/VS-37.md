# VS-37 — Evidence-Aware Today Cooldown Repair

## Status
Active / Implementing.

## Purpose
Repair Today duplicate suppression so a Knowledge Pack Opportunity pattern can be reconsidered inside its normal cooldown when the owner materially changes the goal/evidence that pattern actually uses, without allowing unrelated Context edits to create repetitive recommendations.

## Base
Merged VS-36 main: `48f1ecd6359ff9beb74687fe2aeead1d2afb3802`.

## Authority
- PRD Opportunity eligibility, FR-05 and FR-07
- TRD evidence/provenance and deterministic application-policy boundaries
- DESIGN v1.2 truthful Today/no-focus behavior
- PES/Loop governance
- Existing Knowledge Pack `CooldownDays` policy

## Scope
- resolve pattern evidence before cooldown evaluation;
- compute deterministic cooldown identity from pattern + goal context + resolved EvidenceIds;
- persist `cooldownFingerprint` in future Opportunity EvidenceJson snapshots;
- derive equivalent identity from complete schema-v1 historical snapshots;
- conservatively suppress same-pattern legacy records when identity cannot be derived;
- preserve existing ranking, cooldown durations, policy-only eligibility, owner decisions and no-focus behavior.

## Explicit non-goals
- changing Knowledge Pack cooldown durations;
- using whole Business/Knowledge bundle fingerprints as duplicate identity;
- adding new Opportunity patterns or generic fallback recommendations;
- changing Today UI/navigation/copy;
- changing action-decision status semantics;
- database migration/backfill;
- connectors, model prompts/providers or external action;
- production release, EAS/OTA or production database mutation.

## Success
Same recommendation identity remains suppressed; materially changed relevant evidence can generate a fresh eligible candidate; irrelevant Context changes cannot defeat cooldown; historical real Opportunities continue to suppress accurately without backfill; incomplete historical snapshots fail closed.
