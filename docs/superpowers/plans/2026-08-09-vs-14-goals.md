> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate Atlas Goals to the approved visual system while preserving the authenticated FR-04 API boundary and making ordering, custom-goal validation, state feedback, and accessibility deterministic.

**Architecture:** Keep `apps/mobile/app/(tabs)/goals.tsx` as the Expo Router route with local session/API/form ownership. **Tech Stack:** Expo SDK 54, Expo Router 6, React 19.1, React Native 0.81, TypeScript 5.9, Node built-in test runner, PES governance.

## Global Constraints

- Requirement scope is FR-04 only; preserve the approved `BusinessGoal` DTO and `GET/PUT /api/v1/businesses/{businessId}/goals` behavior.
- Preserve Expo Router, authentication/session ownership, API boundaries, Business isolation, vertical-slice architecture, and local Goals state ownership.
- Starbucks getdesign palette, warm neutrals, hierarchy, spacing, cards, forms, buttons, and depth are the primary visual grammar; Atlas remains the identity.
- Every prototype mark rendering uses `BrandMark`; no screen-level asset URI, Starbucks label, retail imagery, fabricated business data, or generic grey/dark Expo theme is permitted.
- Preserve the existing three approved starter goals; do not add removal, deactivation, drag-and-drop, analytics, new generic-goal selection, API/domain behavior, or migrations.
- Use real behavior tests, not source-text assertions. Use TDD for ordering, validation, state presentation, and regressions.
- Minimum interactive targets are 44 points; support screen readers, dynamic text, logical order, non-colour status, keyboard-safe scrolling, 390×844, and 768×1024.
- Do not add dependencies, deploy, release, create an EAS build, publish OTA, or enable production.
- Exact-head local checks, CI, Security baseline, Product Intake, governance, certification, and the already authorized human merge gate are required before merge.

- [ ] **Step 3: Implement the pure model**

Create `goals-model.ts` with:

```ts
import type { BusinessGoal } from '@/api/atlas-client';

export const MAX_GOALS = 10;
export const starterGoals = [
  { title: 'Increase revenue', type: 'revenue', priority: 1, isCustom: false },
  { title: 'Improve profitability', type: 'profitability', priority: 2, isCustom: false },
  { title: 'Save owner time', type: 'efficiency', priority: 3, isCustom: false }
] as const satisfies readonly BusinessGoal[];

function normalize(goals: readonly BusinessGoal[]): BusinessGoal[] {
  return goals.map((goal, index) => ({ ...goal, priority: index + 1 }));
}

export function sortGoals(goals: readonly BusinessGoal[]): BusinessGoal[] {
  return normalize([...goals].sort((left, right) => left.priority - right.priority));
}

export function moveGoal(goals: readonly BusinessGoal[], index: number, delta: -1 | 1): BusinessGoal[] {
  const target = index + delta;
  if (index < 0 || index >= goals.length || target < 0 || target >= goals.length) return [...goals];
  const next = [...goals];
  [next[index], next[target]] = [next[target], next[index]];
  return normalize(next);
}

export function addCustomGoal(goals: readonly BusinessGoal[], input: string): { goals: BusinessGoal[]; error: string | null } {
  const title = input.trim();
  if (!title) return { goals: [...goals], error: 'Enter a goal before adding it.' };
  if (goals.some(goal => goal.title.trim().toLocaleLowerCase() === title.toLocaleLowerCase())) return { goals: [...goals], error: 'That goal is already in your priorities.' };
  if (goals.length >= MAX_GOALS) return { goals: [...goals], error: 'Atlas supports up to 10 active goals.' };
  return { goals: normalize([...goals, { title, type: 'custom', priority: goals.length + 1, isCustom: true }]), error: null };
}

export function getGoalsSavePresentation(saving: boolean, saveEnabled: boolean) {
  return {
    accessibilityLabel: saving ? 'Saving business goals' : 'Save business goals',
    accessibilityState: { busy: saving, disabled: !saveEnabled },
    ariaBusy: saving,
    text: saving ? 'Saving…' : 'Save goals'
  } as const;
}

export function getGoalsStatePresentation(state: 'loading' | 'missing') {
  return state === 'loading'
    ? { title: 'Loading your goals', copy: 'Gathering the priorities Atlas uses to evaluate future opportunities.' }
    : { title: 'No business selected', copy: 'Choose or create a business before you update goals.', action: 'Choose or create a business' };
}
```
